# Rock Drill Quality Platform V2

面向单一制造企业的模块化 PLM 与质量数据平台。第一阶段聚焦零件质量检测闭环，并为后续轻量级 PLM 能力预留演进空间。

## 当前状态

Slice 0A（项目控制基线）已完成，项目控制基线已建立。当前尚无业务代码、数据库 Schema、框架或依赖；没有获授权的实施计划，禁止自动开始 Slice 0B。
